# TypeRush

Multiplayer typing battles with Casual and Ranked modes, accounts, ELO matchmaking, rooms, configurable typing rules, and Socket.IO synchronization.

## Local development

```bash
npm install
npm start
```

Open `http://localhost:3000`.

## Render

This repository is configured for Render Node 20 and does not include `node_modules` or local SQLite database files.

See `DEPLOY-RENDER.md` for the exact Render configuration.
